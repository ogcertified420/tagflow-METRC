# Room Map Screen

## Purpose
Show a visual grid of plant slots in a room.

## Header
- Room name
- Back button
- Refresh button
- Scan Tag button

## Grid
Each slot is a square.

### Empty slot
Shows:
- Empty label or plus icon

Tap action:
- Open Add Plant flow

### Occupied slot
Shows:
- Tag number
- Optional strain name

Tap action:
- Open Plant Action Menu

## Plant Action Menu
Buttons:
- Move
- Harvest
- Destroy
- Details
- Cancel
